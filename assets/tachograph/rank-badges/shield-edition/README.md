# Tachograph shield edition

22 redesigned rank shields in the style of the approved 75K Horizon Wolf. The archive contains 44 individual WebPs: full-colour unlocked and muted silver locked with padlocks. Master canvases are 176 × 218 px. The approved card's individual slot dimensions and coordinates are in placements.csv. Use fit_slot.py to export any rank/state into the exact transparent canvas of any front, featured back or rank grid slot. This is a new artwork edition and does not alter the reference crops or live renderer.
