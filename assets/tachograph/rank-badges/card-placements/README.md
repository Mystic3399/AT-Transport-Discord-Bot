# Approved card badge placements

27 lossless WebP crops from the approved 1117 × 1408 artwork: 3 front badges, 2 featured back badges, and all 22 reverse rank cells. Coordinates in placements.csv are pixels from the top-left of the combined reference. Crops preserve the original backgrounds, labels and rank states visible on the approved design. These are position-specific reference assets. The source mockup shows one state per slot, so it does not supply alternate-state artwork for every rank in this style.
